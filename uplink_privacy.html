隐私政策

本应用非常重视用户隐私保护，本政策用于说明应用如何使用相关权限与信息，所有行为均遵循合法、正当、必要原则。

1. 权限使用说明

  • WiFi 与蓝牙权限：用于周边设备的发现、连接与通信，仅在使用设备连接功能时使用。
  • 网络权限：用于设备固件 OTA 升级、版本更新及与设备进行网络通信。
  • 相册/存储权限：仅用于将图片、视频保存到用户本地相册，不会上传或收集任何图片、视频内容。

2. 信息收集与使用

本应用不会收集、上传、存储用户个人身份信息，不会获取手机号、位置信息、通讯录、短信等隐私数据。

所有权限仅用于实现本地功能与设备通信，不会用于广告、统计或其他无关用途。

3. 信息共享与披露

本应用不会向任何第三方共享、出售、转让用户的任何信息。

仅在法律法规、司法机关强制要求时，才会依法进行披露。

4. 用户权利

  • 用户可随时在系统设置中开启或关闭相关权限。
  • 关闭权限仅影响对应功能使用，不会影响应用其他基础能力。
  • 用户可随时卸载应用，终止所有权限与数据使用。

5. 信息安全

本应用仅在本地完成数据处理，所有通信仅面向用户自己的设备，采取必要措施保障连接与数据安全。

6. 政策更新

如应用功能或权限调整，本政策会相应更新，并在应用内展示。

Privacy Policy

This application attaches great importance to user privacy protection. This policy explains how the app uses relevant permissions and information. All behaviors comply with the principles of legality, legitimacy, and necessity.

1. Permission Usage

  • WiFi & Bluetooth Permission: Used for device discovery, connection, and communication only when using the device connection feature.
  • Network Permission: Used for device firmware OTA updates, version updates, and network communication with connected devices.
  • Photo Gallery / Storage Permission: Only used to save images and videos to the user's local album. No images or videos will be uploaded or collected.

2. Information Collection & Use

This app does NOT collect, upload, or store any personal identifiable information, including phone number, location, contacts, SMS, or other private data.

All permissions are used only for local functions and device communication. No advertising, tracking, or unrelated usage.

3. Information Sharing & Disclosure

This app will not share, sell, or transfer any user information to third parties.

Only when required by laws, regulations, or judicial authorities will information be disclosed in accordance with the law.

4. User Rights

  • Users can enable or disable permissions at any time in system settings.
  • Disabling permissions only affects related functions, not basic app usage.
  • Users can uninstall the app at any time to terminate all permission and data usage.

5. Information Security

All data processing is performed locally. Communication is only between the app and user-owned devices. Necessary measures are taken to ensure connection and data security.

6. Policy Updates

This policy may be updated with app functions or permission changes and will be displayed within the app.

Effective Date: 2026-04-03
